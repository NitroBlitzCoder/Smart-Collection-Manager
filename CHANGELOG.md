# Smart Collection Manager Free 1.1.1

Updated free-edition source and installable extension package, including manifest, supporting modules and README.

Open the Scene Tools sidebar. Sort active-scene objects by type, rename selected objects, inspect statistics, or hide empty private collections. Start with Exclusive Sort disabled when preserving existing collection memberships.

Minimum Blender version: 5.0.0. Validation scope and limitations are documented in README.md; support is not a guarantee across every scene, platform or render engine. Paid-edition packages are not distributed in this repository.
