# Smart Collection Manager
> Stop organizing manually. Let your scene manage itself.

Smart Collection Manager is a Blender addon that automates scene organization. 
Whether you're dealing with imported assets dumping dozens of objects into your 
outliner or a long-term project that's grown out of control, SCM keeps things 
clean and structured automatically.

---

## Features

### Free
- Auto-sort objects by type (Meshes, Lights, Cameras, Curves, Armatures)
- Object batch renaming utilities
- Scene statistics overview
- Auto-hide empty collections

---

## Installation

1. Download the `.zip` from [Releases](../../releases)
2. In Blender, go to `Edit > Preferences > Add-ons > Install`
3. Select the downloaded `.zip` and enable the addon

**Requires:** Blender 4.0+

---

## Usage

Access all features from the sidebar panel: `N Panel → SCM`

Auto-sort runs on demand or can be set to trigger on file load via preferences.
